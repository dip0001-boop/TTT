# Tung Tung Search

Tung Tung is a polished, privacy-first metasearch engine designed to run on Render.

## Features

- Web search
- Images
- News
- Videos
- Wikipedia-style knowledge results
- Search autocomplete
- Safe Search
- Dark mode
- Light mode
- Responsive mobile design
- Pagination
- No local search-history database
- No paid API keys
- Render-ready Node.js server
